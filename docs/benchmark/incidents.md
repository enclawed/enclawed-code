# Documented agent-layer incidents

Every documented security incident and published exploit involving agentic AI, from 2023 to November 2026, that exploited a gap in an agent the operator runs locally or in continuous integration (40 incidents; the paper's Table of incidents groups them by gap). Gap: the weakness exploited. Prevented: whether Enclawed around the agent prevents the harmful action on the incident's weakest route: Yes (rule), a deterministic rule refuses it whatever a person answers; Yes (approval), it is held until a person explicitly approves that one action, and refused when no one does; No, it runs. Evidence: Reproduced, a scenario of the live benchmark reproduces the incident's mechanism and has been run (its outcome is in per-scenario-*.md); Rule + test, the deciding rule is covered by a named test (a reproduction may be written and await its live run); Reasoned, neither. Decided by: the deciding rule, named by the section of the paper's Methods that describes it. For products other than Claude Code the verdict says what an Enclawed-style layer around that agent would do, not that codenclawed was tested on it. 35 further incidents reported as agentic AI incidents exploit no gap an agent layer can reach (hosted services, dependency flaws, attackers' own agents) and are not listed.

Rows: 40. Machine-readable copy: [incidents.csv](incidents.csv). Generated by the paper's `scripts/make-tables.mjs`; do not edit by hand (see [README.md](README.md)).
